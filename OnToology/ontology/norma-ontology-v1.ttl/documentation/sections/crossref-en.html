Annotator Agentc back to ToC or Class ToC

IRI: https://w3id.org/norma-ontology#AnnotatorAgent

A provenance agent responsible for creating, reviewing, or attesting to a NORMA annotation. May represent a person (legal expert, analyst), a software system (LLM extractor, rule engine), or an organization. For finer-grained typing use the corresponding PROV-O subclasses (prov:Person, prov:SoftwareAgent, prov:Organization). Integrity constraint (not OWL-enforced): for a given NormativeContent, `prov:wasAttributedTo` and `prov:wasAssociatedWith` (via its generating AnnotationActivity) should resolve to the same agent; validate with SHACL.
Is defined by
https://w3id.org/norma-ontology
has super-classes
agent
is in domain of
is annotator of op, was annotator associated with activity op
is in range of
was associated with annotator op, was attributed to annotator op

Legal Agentc back to ToC or Class ToC

IRI: https://w3id.org/norma-ontology#LegalAgent

IRI: https://w3id.org/norma-ontology#TriggerEvent

Reified instance of the triggering relation between a legal condition, one evaluated condition outcome, and one activated normative content item. Represents true, false, and other branch-specific activations without using separate branch-label datatype properties. Follows Pattern 1 / Use Case 1 of the W3C Working Group Note Defining N-ary Relations on the Semantic Web.
