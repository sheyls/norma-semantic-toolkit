
# BPMN to Rules

This software transforms a legal compliance processes represented using BPMN that follows a specific template into executable rules. 

# Requirements

1. Download and install [Camunda Modeler](https://camunda.com/platform/modeler/). It is [open source](https://github.com/camunda/camunda-modeler). 

2. Download [template](https://example.com) and copy the `json` file to:

Windows:
`C:\Users\sheyls\AppData\Roaming\camunda-modeler\resources\element-templates`

Linux:
`/home/sheyls/.config/camunda-modeler/resources/element-templates`

macOS:
`/Users/sheyls/Library/Application Support/camunda-modeler/resources/element-templates`

If the folder `element-templates` does not exists, feel free to create it.


1. You should be able to create BPMN compliance processes, using the [template](https://example.com). In order to edit the BPMN, you need to use [Camunda Modeler](https://camunda.com/platform/modeler/), which is free.
